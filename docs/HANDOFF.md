# 왁뿌볼 (Slime Wakppu Ball) 프로젝트 핸드오프 문서

이 문서는 토스 앱인앱(App-in-App) 플랫폼용 **'슬라임 왁뿌볼(Slime Wakppu Ball)'** 미니앱 프로젝트의 현재까지 진행 사항, 기술 스택, 구현된 내용 및 향후 계획을 요약한 핸드오프(Handoff) 문서입니다.

---

## 1. 프로젝트 개요 및 인터뷰 요약

* **프로젝트명:** 왁뿌볼 (Slime Wakppu Ball)
* **목표:** 토스 앱 내에서 구동되는 미니앱으로, 실제 왁뿌볼을 만지는 듯한 촉감과 시각적, 청각적 피드백(ASMR)을 3D 인터랙션으로 제공하는 서비스.
* **핵심 레퍼런스:** [포켓몬 카드 CSS (토스 미니앱 레퍼런스)](https://minion.toss.im/54aNEoEy)와 같이 코드로 현실 사물의 물리적 인터랙션을 극대화하여 몰입감을 주는 앱.
* **서비스 전략 (게이미피케이션):**
  * 포인트를 모아 새로운 단계의 왁뿌볼을 구매/성장시킴 (총 3단계).
  * '친구에게 공유하기' 등 바이럴 액션을 통해 포인트를 획득, MAU를 유지하는 전략.
* **디자인 원칙:** 토스 디자인 시스템(TDS)과 UI/UX 가이드를 '골든 룰'로 삼아 유려한 바이브 코딩(Vibe Coding) 지향.

---

## 2. 기술 스택 (Tech Stack)

* **프레임워크:** Next.js 16 (App Router), React
* **스타일링:** Tailwind CSS v4, Framer Motion (UI 트랜지션 및 애니메이션)
* **3D 렌더링:** Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`)
* **상태 관리:** Zustand (포인트 및 레벨 전역 상태 관리)
* **기타 라이브러리:** `clsx`, `tailwind-merge`

---

## 3. 현재 구현 완료 사항 (v0.1)

1. **기본 환경 및 가이드 설정:**
   * Next.js 프로젝트 생성 완료 (`/home/hy3jun/문서/Slime Simulation`).
   * 토스 미니앱 개발 가이드, TDS 컴포넌트, UX 가이드를 크롤링하여 `docs/TOSS_GUIDELINES.md` 에 에이전트 참조용으로 통합 및 저장 완료.
2. **3D 왁뿌볼 렌더링 엔진 구축:**
   * `src/components/WakppuBall.tsx`: `MeshDistortMaterial`을 활용하여 슬라임의 꿀렁거리는 표면과 질감을 3D로 구현.
   * 사용자 클릭/터치 시 왁뿌볼이 찌그러지는 물리적 애니메이션(Scale Lerp) 적용.
   * 모바일 환경 대응: 터치 시 `navigator.vibrate`를 통한 햅틱(진동) 피드백 연결.
   * 레벨별 색상 변화 (1단계: 블루, 2단계: 옐로우, 3단계: 레드).
3. **게이미피케이션 상태 관리:**
   * `src/store/useStore.ts`: 현재 소지 포인트(points)와 왁뿌볼 레벨(level)을 관리하는 Zustand 스토어 생성.
   * 포인트 획득 및 포인트 차감을 통한 레벨업 로직 구현 완료.
4. **TDS 기반 메인 UI 적용:**
   * `src/app/page.tsx`: 토스 특유의 폰트(Toss Product Sans), 여백, 글래스모피즘(Backdrop Blur)을 적용한 메인 화면 구축.
   * Framer Motion을 사용한 부드러운 UI 등장 애니메이션 적용.
   * '공유하고 포인트 받기' 및 '새로운 왁뿌볼 얻기(레벨업)' 버튼 기능 연동.

## 4. 해결해야 할 과제 및 다음 단계 (Next Steps)

1. **ASMR 사운드 추가 (우선순위 높음):**
   * 슬라임을 만질 때 나는 '찌그덕', '말캉'거리는 소리를 Web Audio API나 HTML5 Audio를 사용해 터치 이벤트와 동기화시켜야 합니다. 촉감(진동) + 시각(3D 변형) + 청각(ASMR)의 3박자 완성이 목표입니다.
2. **토스 SDK 연동 (Toss App-in-App):**
   * 실제 토스 앱 내에서 구동되기 위해 필요한 [Toss 미니앱 SDK] 연동. (공유하기 기능 네이티브 연결 등)
3. **3D 물리 엔진 고도화:**
   * 현재는 클릭 시 단순히 스케일이 줄어드는 애니메이션입니다. 더 실제 같은 '왁뿌볼' 느낌을 위해 포인터 위치에 기반한 드래그(Drag) 찌그러짐이나 파티클 이펙트 추가를 고려해볼 수 있습니다.
4. **로컬 스토리지 연동:**
   * Zustand의 `persist` 미들웨어를 사용하여 새로고침해도 사용자의 레벨과 포인트가 날아가지 않도록 저장 로직을 추가해야 합니다.
