# 왁뿌볼 (Wakppu Ball) PRD (Product Requirements Document) 초안

## 1. 프로젝트 개요
*   **프로젝트명:** 왁뿌볼 (Wakppu Ball - 슬라임 시뮬레이션)
*   **목적:** 유저가 화면을 통해 '슬라임 왁뿌볼'을 만지며 소리와 촉감을 간접적으로 느낄 수 있는 극도의 인터랙티브 웹(앱인앱) 서비스 제공
*   **개발 철학 (포켓몬 카드 CSS 레퍼런스 방향성):** 현실 세계의 물리적인 물건(왁뿌볼)을 코드로 정교하게 재현하여, 유저가 조작할 때 시각적/청각적/촉각적 즐거움을 느낄 수 있는 하이퀄리티 인터랙션 구현
*   **주요 전략:**
    *   새로운 왁뿌볼 수집(구매)을 목표로 하는 게이미피케이션(포인트) 시스템
    *   공유 시 포인트 보상을 통한 바이럴 마케팅

## 2. 유저 스토리 (User Stories)
*   사용자는 화면 중앙의 왁뿌볼을 터치하고 드래그하며, 실제 슬라임을 만지는 듯한 시각적/청각적 피드백(ASMR 등)을 즐길 수 있다.
*   사용자는 출석이나 공유 등의 행동으로 포인트를 모을 수 있다.
*   사용자는 모은 포인트를 사용하여 단계별로 총 3가지의 새로운(서로 다른 특성을 가진) 왁뿌볼을 해금하고 구매할 수 있다.
*   사용자는 친구에게 앱을 공유하고 보상(포인트)을 받을 수 있다.

## 3. 핵심 기능 (Core Features)
1.  **초실감 인터랙티브 왁뿌볼 시뮬레이션 (핵심 가치)**
    *   터치, 스와이프, 꾹 누르기 등에 반응하는 쫀득한 슬라임 물리 효과
    *   시각적 효과에 맞춘 사운드 피드백 (ASMR) 및 진동 햅틱 피드백(기기 지원 시)
2.  **포인트 및 상점 시스템**
    *   초기 3개의 왁뿌볼 라인업 (기본 -> 2단계 -> 3단계 왁뿌볼)
    *   앱 공유 및 특정 조건 달성 시 포인트 지급 메커니즘
3.  **Toss 미니앱 연동**
    *   토스 플랫폼 내에서 이질감 없는 '토스 바이브' UI/UX 적용
