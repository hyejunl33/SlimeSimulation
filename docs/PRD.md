# 왁뿌볼 (Wakppu Ball) PRD v0.4

## 1. 프로젝트 개요
*   **프로젝트명:** 왁뿌볼 (Wakppu Ball) - 토스 앱인앱 슬라임 시뮬레이션
*   **목적:** 유저가 화면의 3D 왁뿌볼을 드래그하고 늘리며 촉감(햅틱)과 소리(ASMR)를 간접적으로 느끼는 극도의 인터랙티브 웹 서비스
*   **개발 철학:** 현실의 장난감을 코드로 정교하게 재현 (포켓몬 카드 CSS 기법처럼, 빛 반사/홀로그램/물리법칙 등을 적용하여 쾌감 극대화)
*   **주요 전략:**
    *   3가지 종류의 왁뿌볼 수집을 목표로 하는 포인트 레벨업(게이미피케이션)
    *   토스 앱 내 공유 기능(`bridge.share`)을 통한 바이럴 마케팅
    *   지속 접속을 유도하는 출석 포인트 시스템

## 2. 핵심 기능: 초실감 왁뿌볼 3종 (시각/청각/촉각)
유저는 포인트를 모아 총 3단계의 왁뿌볼을 수집할 수 있으며, 단계별로 완전 히 다른 물리적/시각적/청각적 피드백을 제공합니다.

### 🟢 Level 1: 왁스볼 (WAX BALL) - 기본 지급
*   **시각 (3D Shader):** 맑은 아이시 블루 기반, 터치 방향으로 미세하게 표면이 갈라짐(Crack), 포켓몬 카드와 같은 홀로그램(Rainbow Fresnel) 빛 반사
*   **청각 (Web Audio API):** 바스락/빠작 거리는 고주파 크래킹 ASMR (HighPass Filter 3000Hz~)
*   **촉각 (Haptic):** 50ms의 짧고 경쾌한 단발 진동

### 🟡 Level 2: 버터볼 (BUTTER BALL) - 500P 필요
*   **시각 (3D Shader):** 크림 옐로우 컬러, 불투명하고 쫀득한 질감. 포인터 방향으로 찌이익 늘어나는(Stretch) 강한 왜곡 효과 (Simplex Noise)
*   **청각 (Web Audio API):** 뽁뽁거리는 무겁고 점성 있는 소리 (LowPass Filter 80Hz + 공명)
*   **촉각 (Haptic):** [80, 30, 80] ms의 길고 부드러운 연속 진동

### 🔴 Level 3: 구슬볼 (BEAD BALL) - 1,500P 필요
*   **시각 (3D Shader):** 투명한 유리막(Transmission 0.95) 안에 150개의 컬러풀한 작은 구슬(InstancedMesh) 파티클이 들어있는 구조.
*   **청각 (Web Audio API):** 차르르 부딪히는 다발성 알갱이 소리 (다중 BandPass Filter 충돌음)
*   **촉각 (Haptic):** [15, 10, 15, 10, 15] ms의 다발적 알갱이 진동
*   **물리:** 스마트폰 기기를 기울이면(DeviceOrientation) 구슬들이 중력 방향으로 쏠리는 인터랙션

## 3. 포인트 및 게이미피케이션 시스템
*   **초기 자본:** 접속 시 100P 지급
*   **출석 포인트:** 24시간 주기로 접속 시 20P 지급
*   **바이럴 공유:** 토스 앱 공유하기 버튼 클릭 시 100P 즉시 지급
*   **저장 방식:** Zustand Persist를 활용한 로컬 스토리지 데이터 유지

## 4. UI/UX 디자인 가이드 (TDS)
*   Toss Design System (TDS)을 엄격히 준수하여 토스 앱인앱 환경에 이질감 없이 녹아들도록 구성
*   폰트: Toss Product Sans
*   버튼 스타일: `h-[56px]`, `rounded-[16px]`, `bg-[#3182f6]` (Toss Blue)
*   여백/컬러: `gray-50` 배경, 직관적이고 깔끔한 토스 바이브 카드 레이아웃

## 5. 배포 및 토스 미니앱 연동
*   **배포 환경:** Vercel (HTTPS 필수)
*   **토스 연동:** `@tossteam/toss-miniapp-sdk` 설치 후 네이티브 공유 시트(`bridge.share`) 호출
